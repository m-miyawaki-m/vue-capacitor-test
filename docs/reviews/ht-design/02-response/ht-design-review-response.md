# 設計書レビューへの対応

[Claude のレビュー記録](../01-review/ht-design-review.md) · [反映後の要件定義](../../../01-requirements/ht-design.md)

| 指摘 | 対応 |
| --- | --- |
| M1・M2 | 初回の範囲・対象外、採用技術、Android ビルド条件と検証コマンドを記載した。依存の具体版と実機・エミュレーター構成はセットアップ時に確認する。 |
| M3・M4 | 疎通時の入力・出力・ログ・エラーと、撮影成功・キャンセル・拒否・Web の受入基準を定義した。 |
| S1・S2 | 読み取り画面を将来案と明記した。詳細から戻ると検索条件・一覧・スクロール位置を復元する方針に揃えた。 |
| S3・S4・S5 | Store に取得失敗・同時取得の方針を追加した。API のエラー表示・再操作は後続の詳細設計項目とし、仕様外キーの既定は除去とした。 |
| S6・S7 | 疎通テストと手動確認の記録項目を追加し、レスポンス Store の呼称を揃えた。 |
| S8 | GitHub 準備前の記録先を `docs/records/` とした。Git の初期化方法は実装準備時に決める。 |
| N1・N7・N8 | `open.yaml` の配置、資料間の戻りリンク、物理キーと画面サイズの検討項目を追加した。 |
| N2〜N6 | 図の検索フッター、カード、戻る操作、セル ID、読み取り結果と関連業務の遷移を更新した。 |

初回構成に Vue Router を含め、初期ルート `/` に疎通確認画面を割り当てる。業務画面のルートは業務実装の段階で追加する。

## 再レビューへの対応

[Claude の再レビュー記録](../03-rereview/ht-design-rereview.md)

- R-M1・R-S1 は CAMERA 権限の宣言と拒否の再現手順、エラーコード別の挙動とテストを追加した。
- R-S2・R-S3 は Vuetify 4 を初回画面に使い、入力欄から Java の不正入力を確認できる構成とした。
- R-S4 の Git 初期化方法と Android 実行環境は実装準備時に決める。
- R-N1〜R-N4 は TypeScript の選定基準、Router の履歴モード、図の注記と遷移先を更新した。

## Claude の最終確認

Claude Code（Herdr `w3:p2`）が R-M1 の修正を確認した。Android の CAMERA 権限の宣言、拒否の再現と判定方法、画面テストと実機での受入確認が記載されているため、must の残件は 0 件。「方針に同意します」と回答した。今回の最終確認は R-M1 が対象。
