# Android アーキテクチャの方針レビュー

Claude Code（Herdr `w3:p2`）は方針に同意した。must 0件、should 3件、nit 3件。

- should。Android の API ベース URL と CORS、初回に扱う層、対象 HT の WebView とビルド対象の整合を明記する。
- nit。Web 疎通のコンソール出力、端末機能コードの配置、別資料の古いレビュー状況を揃える。
