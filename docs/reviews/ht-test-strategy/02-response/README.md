# テスト方針と業務シナリオへの指摘対応

- M1。受入基準 AC1〜AC5 の対応表を追加し、Store・API 境界、UI、画面とデータの結合、コード生成のケースを定義した。
- S1・S2。業務シナリオは画面で観察できる結果を記載し、HTTP リクエストと固定データの確認をテストケースに置いた。
- N1・N2。在庫照会の業務フローを定義項目に沿って表にした。HTTP 500 と契約不一致は別ケースにした。
